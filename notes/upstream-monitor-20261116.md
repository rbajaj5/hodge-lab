## Submission guidance and atlas displays

Upstream now asks solution explanations to cite earlier solves and book sections by name and link repository files by path. The pre-Lean renderer rejects PR references, links to repository files by GitHub URL, and single-dollar inline math. For discussion comments the guide specifies GitHub `main` links to the book, instance records and motivations, and solutions. It also permits external sources such as papers and Prove2Me. This supersedes the website-page link guidance recorded on 11 November. The restrictions on PR links and shorthand still apply to comments. Hodge Lab’s ledger audit remains required before any separately authorized upstream publication.
